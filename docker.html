Project Overview: DockerFolio Containerization Platform

WHAT IS DOCKERFOLIO?

DockerFolio is an automated, containerized personal web portfolio application designed to showcase technical projects, code repositories, and DevOps skills in a lightweight microservice environment.

DockerFolio

App v1.0
Core Purpose

Reproducible Deployment

To transform static web assets (html, js, photos) into a portable, reproducible service that can be seamlessly built and deployed via automation.

Eliminate Manual Setup

Standardize deployment by packaging application runtime, dependencies, and configurations into a standardized Docker image (portfolio-web:1.0).

Infrastructure Portability

Guarantee consistent execution across diverse infrastructure, including Ubuntu and CentOS target nodes, via Ansible automation (docker_image.yml).

Continuous Availability

Enforce automated service mapping (port 80) and restart policies (always) for constant web app availability.
